Overview

Le csPCa est une atteinte maligne de la prostate significative cliniquement. Le projet évalue un détecteur d'apprentissage profond sur des examens IRM biparamétriques (T2W, ADC, DWI/HBV), avec deux axes : validation d'un modèle de détection, puis analyse de l'interprétabilité de ses décisions.

5 × UNet 3D
Ensemble k-fold : 31.8 M paramètres/fold, 127.2 Mo de poids checkpoint, structure features officielle
20×256×256
Grille d'entrée par modalité, espacement officiel (3.0/0.5/0.5 mm) — 3 canaux T2W/ADC/HBV
7 cases
Cas de démonstration locaux passés dans le pipeline réel (vérité terrain de la marksheet officielle)
Honnêteté expérimentale : le détecteur utilisé a été entraîné par ses auteurs sur les 1 500 examens publics PI-CAI ; les cas locaux d'évaluation ont donc été observés à l'entraînement. Les métriques présentées sont une borne supérieure d'usage : le travail porte sur la qualité de l'instrumentation (reproduction exacte, évaluation sans fuite, seuil figé sur validation, explicabilité auditée), pas sur la performance en généralisation externe.

Le seuil de décision

Aucun seuil « arrange » les résultats : la Phase 1 utilise le seuil officiel publié, la Phase 2 documente une recalibration figée sur la seule validation avant tout accès au test.

Phase 1 — seuil officiel

0.50

Origine : point opératoire de l'évaluation PI-CAI (Saha et al., Lancet Oncology 2024 : sensitivity 70,9 % / PPV 35,5 % au seuil 0,50 sur le jeu test du concours). Chaque exemple ci-dessus applique strictement cette règle.

Phase 2 — recalibration sur validation

0.1572

Règle préenregistrée : choïx de la configuration de post-traitement par AP maximale en validation, seuil = max-F1 en validation ; le test n'est scoré qu'une seule fois après gel. C'est l'unique « changement de seuil » du projet, et il est mesurable.

Phase 2 — Explainable AI

Transition : le modèle permet d'obtenir une prédiction à partir des données d'imagerie ; la prédiction seule ne dit pas ce qui a motivé la décision. La Phase 2 introduit donc les méthodes XAI afin d'analyser cette décision, s'appuyant sur une évaluation élargie (240 cas) et une règle figée avant le test.
